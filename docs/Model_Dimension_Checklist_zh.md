# 模型尺寸核对清单（单位 mm）

在 CATIA 里用 Measure Between / Measure Item 量这些尺寸，和下面的"应为"值对照。

## 1. 弯管 elbow_pipe（最重要，对应题目规格）

| 检查项 | 应为 | 来源 |
|---|---|---|
| 外径 OD | 215 | 题目给定 |
| 内径 ID | 185 | 外径减 2 × 壁厚 15 |
| 壁厚 | 15 | 题目给定 |
| 弯曲半径（管中心线） | 150 | 由题目"高度 150"推断，理解为中心到端面距离 |
| 弯曲角度 | 90° | 视频 |
| 整体外形 | 257.5 × 257.5 × 215 | 150 + 107.5，高度为外径 |
| 体积 | 约 2.22 L | 对应 2.5 kg 时密度约 1.13 g/cm³ |

> 唯一需要你判断的假设是"高度 150"。如果你认为它指别的尺寸（例如端口直管段长度），告诉我，我改模型和程序。

## 2. 其他零件

| 零件 | 关键尺寸 |
|---|---|
| gasket 垫片 | 外径 185（等于管内径），内径 161，宽 20 |
| interim_station 中间工位 | 台面 600 × 500，台面高 600；托块顶面高 630 |
| packing_box 纸箱 | 外形 572 × 572 × 466，壁厚 6；内腔 560 × 560 × 460 |
| vacuum_gripper 吸盘 | 法兰 Ø80；吸盘唇口（TCP）距法兰 175 |
| box_conveyor 辊筒线 | 1400 × 700；辊筒顶面高 400 |
| robot_stand 底座 | 400 × 400 × 400 |

## 3. 装箱能否放下

- 2 × 2 排列：2 × 257.5 = 515 < 560，件间隙 23，离箱壁 12。
- 2 层：2 × 215 = 430 < 460。

## 4. 总装位置（世界坐标，机器人底座中心在地面原点）

| 零件 | 位置 | 旋转 |
|---|---|---|
| 中间工位 | (700, −200, 0) | 无 |
| 辊筒线 | (−150, −750, 0) | 无 |
| 纸箱 | (−150, −750, 400) | 无 |
| 弯管（传送带上） | (400, 540, 600) | 绕 Z 轴 45° |
| 弯管（中间工位上） | (625, −275, 630) | 绕 Z 轴 45° |
| 垫片 | (775, −275, 737.5) | 绕 X 轴 −90° |

"绕 Z 轴 45°"只适用于 CATIA 宏建出来的弯管；STL 里的弯管不需要旋转。
